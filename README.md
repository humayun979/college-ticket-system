# college-ticketing-system


The Campus Service Management System is a web-based ticketing application designed to streamline communication and service requests between students, users, and administrative staff within a college environment. The platform allows users to submit, track, and manage service tickets while providing administrators with tools to organize, prioritize, and monitor requests efficiently.

The system includes features such as role-based access, ticket status tracking, priority filtering, activity history, notifications, and administrative dashboard management. Its modular design allows the platform to be easily adapted and replicated across multiple departments within a college or university, including IT support, academic advising, facilities management, financial aid, and student services.

This project was developed using Agile project management practices and organized through Jira to simulate a real-world software development workflow.
